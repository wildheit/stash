# Stash

[日本語版はこちら](README.ja.md)

An Android app that makes it easy to browse and save just the photos and videos from your X (Twitter) timeline, built by an independent developer.

See the official page for more details and screenshots: **https://wildheit.github.io/nukostash/**

## ⚠️ Important: unofficial, sideloaded app

- **Stash is an unofficial X client and is not affiliated with X Corp. in any way.**
- It is not distributed through Google Play or any other official app store — **it's provided only as a sideloaded APK**, downloaded directly from this repository's Releases.
- Installing it requires enabling "Install unknown apps" on your device. **You install it at your own risk.**
- Because of changes on X's side, the app may stop working without notice. Continued support is not guaranteed.
- **APKs distributed anywhere other than this repository may have been modified.** Please only download from here.
- The source code is not public.

Please only use this app if you agree to the above, at your own risk.

## Download

Download the latest `nukostash-vX.Y.Z.apk` from [Releases](https://github.com/wildheit/stash/releases).

## Privacy

Your login session is stored only on your device and is never sent anywhere other than X (Twitter). No ads or analytics tracking are built in.
