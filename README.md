# Stash

X(Twitter)のタイムラインから写真・動画だけを効率よく閲覧・保存できる、個人開発のAndroidアプリです。

詳しい紹介・スクリーンショットは公式ページをご覧ください: **https://wildheit.github.io/nukostash/**

## ⚠️ 重要: 非公式・野良アプリです

- **Stashは非公式のXクライアントであり、X Corp.とは一切関係ありません。**
- Google Playなどの公式ストアでは配布していません。**このリポジトリ(Releases)からAPKを直接ダウンロードしてインストールする「サイドロード」でのみ提供**します。
- インストールには端末側で「提供元不明のアプリ」の許可が必要です。**自己責任でのインストールになります。**
- X社のAPI仕様変更により、予告なく動作しなくなる可能性があります。継続的なサポートを保証するものではありません。
- **このリポジトリ以外で配布されているAPKは改変されている可能性があります。** ダウンロードは必ずここから行ってください。
- ソースコードは非公開です。

以上に同意いただける方のみ、自己責任でご利用ください。

## ダウンロード

[Releases](https://github.com/wildheit/stash/releases) から最新の `nukostash-vX.Y.Z.apk` をダウンロードしてください。

## プライバシー

ログインセッション(auth_token/ct0)は端末内にのみ保存され、X(Twitter)以外のサーバーへ送信されることはありません。広告・解析トラッキングは組み込んでいません。
